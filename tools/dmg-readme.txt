Superbar: a Windows 7 style taskbar for macOS 26 or later.

INSTALL
1. Drag Superbar onto the Applications folder in this window.
2. Open Applications and double-click Superbar.

THE FIRST TIME YOU OPEN IT
Superbar isn't from the App Store or an identified developer, so macOS stops
it the first time with "Superbar Not Opened". To open it anyway:
1. Click Done.
2. Open System Settings > Privacy & Security, scroll down to Security, and
   click "Open Anyway" next to Superbar.
3. Enter your password, then click Open Anyway again.
You only need to do this once.

PERMISSIONS
Superbar asks for Accessibility, so it can list, switch, snap, and minimize
windows: System Settings > Privacy & Security > Accessibility, turn on Superbar.
For window previews it asks for Screen & System Audio Recording, and to
restart, shut down, or log out it asks to control System Events.

TO REMOVE IT
If Superbar hid your Dock, click Restore Dock in Superbar Settings first.
Then quit Superbar and drag it from Applications to the Trash.
